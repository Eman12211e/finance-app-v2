What changes in the shell

  • One row: brand on the left, five sections in the middle, a single Learn menu and the profile on the right. The three header buttons (Before you buy, Learn about accounts, Sentiment) move into Learn.
  • Each section has an icon and a full name; the selected one is underlined in the accent color and filled, so it does not rely on color.
  • The tabs are a real tablist: only the selected tab is in the Tab order; Left and Right arrows move between tabs, Home and End jump to the first and last. Each tab has a URL (#practice), so links and reloads land on the same section.
  • Under 1180 px the tab names hide and the icons stay (each keeps its name for screen readers); on phones the tabs move to a bottom bar (see mockup 03).
  • A "Skip to content" link appears on the first Tab press.
